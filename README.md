# Student Marks Grade Calculator

This is my first Java project. I created this program while learning Java conditional statements.

The program asks the user to enter their marks and displays their grade based on the marks entered.

## How it works
- Takes marks as input from the user.
- Displays the grade based on the marks.
- Shows Pass or Fail.
- Checks whether the entered marks are valid (0–100).

## Grade System
- 90–100: Grade A
- 80–89: Grade B
- 70–79: Grade C
- 60–69: Grade D
- 50–59: Grade E
- Below 50: Fail

## Concepts I Used
- Variables
- Scanner for user input
- If-else statements
- Logical operators (AND, OR)

## How to Run
Compile the program:

`javac Studentmarks.java`

Run the program:

`java Studentmarks`

Then enter your marks when asked.
